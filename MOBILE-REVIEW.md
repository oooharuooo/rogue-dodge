# Alpha 0.5 mobile review

Portrait gameplay with Up / Jump / Down under the arena. No Attack button: successful dodges trigger weapon counters. Menu pauses combat and holds Test Mode, weapon/enemy/boss/mastery/skill selectors, sound, Collection and changelog.

Horizontal route: T1 combat; T2 rest/shrine/event; T3 rogue/shop/treasure; T4 elite/camp; T5 boss. Events reject spending the final HP and duplicate rewards. Checkpoints retain event choices.

Momentum, Bloodlust and Flame Counter emit skill notifications at hit time. Focus reports a Perfect rescued by the wider window. Guardian reports blocking a hit. Normal counters break Flow before bonus calculation.

Verified: 601 existing checks plus 25 new map/event/trigger checks; browser portrait layouts at requested 320x568, 360x640 and 390x844 (actual CSS dimensions depend on in-app browser scaling), menu, map selection, boss/skill test controls, auto-play and tutorial touch action. No JavaScript errors observed. Physical device testing remains necessary for safe-area, thumb comfort and performance.
