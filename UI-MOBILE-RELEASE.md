# Mobile UI release

- Weapon selection uses four icon cards with separate Details actions; starting/resuming remains unchanged.
- Mastery is one overlay opened from the menu button, with weapon/shared tabs, real unlock progress, filters, stable 4/6-card pagination and tap-to-open detail dialogs.
- Settings and Build sections remain mutually exclusive. Vietnamese/English UI and short keyword dialogs are retained.
- Current weapon Aim/Hit bank/Charge and damage/mastery formulas are retained. The proposed weapon redesign and shield weapon are not implemented.
- Existing reviewed campaign, audio, modular enemy, background, skill and elemental work is included from the current local game.

Validation: all 19 local suites matching the release workflow plus UI/skill/audio/checkpoint/atlas checks passed. Browser verification covers selection, Details, Mastery navigation/close, startup and checkpoint resume. Physical phone playtesting remains the next review step.
